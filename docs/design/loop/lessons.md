# Design-loop lessons (repeat findings; check your screens against every line before DONE)

- One plain sentence per alert or banner; no dash chains.
- Hints name only what is missing ("Add a start date"), never restate the form.
- Figures right-aligned in a fixed right column; tabular numerals; key figure is the one figure-xl.
- Job and stage names use non-breaking hyphens; long names wrap, never truncate the figure.
- Skeletons are shaped like the real content (same rows, same heights).
- One field-label style across a form.
- Phone landscape (height < 500 px): pinned action bar is one compact row; content scrolls above it.
- Error state: "Try again" is the primary button.
- Ticked or selected chip text uses ink colour (contrast passes axe in both themes).
- Unreadable money input never saves as $0.00; refuse with a hint instead.
- Back row is a 48 px target on phone.
- Foreman variants show dates, names, reasons and counts only: no $ anywhere, including aria labels and empty states.
- Unreadable or empty share/percent boxes never count as 0%; block Confirm with a hint (same rule as money).
- Working lines that explain a figure show percents to two places when not whole (30.49%, not 30%), so the line adds up by hand.
- Date inputs read dd/mm/yyyy on every browser and in every capture (en-AU locale), not just iPhone.
- Measure or capture a sheet or page only after it has settled (expectStill in guards.ts); on desktop, scope locators to the visible layout, since phone rows stay in the DOM hidden.
- Meta lines never join facts with "·"; one fact per line or a plain sentence (design lint enforces it).
- Admin screens that need a connection show one "Needs connection" sentence; never also the "will send automatically" offline banner.
- Desktop (≥ 1024 px) uses the width: two columns or the action in the title row, not one 720 px column with empty space.
- Table header cells share the body cells' padding and right edge (≥ 16 px from the border) and one font weight.
- Keep word + number pairs together with non-breaking spaces ("yr 1", "paid ahead $300.00", "8 hours").
- Segmented controls: one outer border, straight 1 px dividers, fill marks the selected option; no per-option rounded borders.
- Compact (landscape) headers keep the label with the key figure ("$7,225.90 owed"), never a bare number.
- Every money value uses the figure style (key figure, inline "Cost to the job", "plus $x GST", detail rows), never bold body text.
- One word per concept across list, detail and form ("Card" everywhere, not "Company card" in one place).
- Balances reconcile on the page: show the earlier balance so earlier + this period − paid = the balance shown.
- Offline, reading stays available (lists, review, detail); only writes show Needs connection.
- An override (waive, skip) never sits above or outranks the main action; the fix path comes first.
- On tablet and landscape, fixed bars (pinned action bar, tab bar) never cover content: bar spans the content column, content pads its bottom by every fixed bar's height.
- Inline links in pinned bars and blocker rows still need a 48x48 px hit area (padding or ::after), and the test measures it; checkTouchTargets exempts inline links.
- No divider directly on an indented sub-line (Includes, meta): the sub-line belongs to the row above, or it gets 8 px clear above its text.
- Report and list detail pages: data starts in the first phone viewport; the range or filter is one "Change" row, actions sit in the title row.
- With nothing to show, disable Export CSV and Print, and give the empty sentence one action button.
- Hub and index pages use one grouped list surface, not a grid of identical bordered cards.
- File names and unit words ("crew-day", ".zip" names) never break at a hyphen: nowrap or non-breaking hyphen.
- `nowrap` only on a short figure or name run that still fits at 200% text zoom; let it wrap (break-words) past the column, never widen the page (export zip name, report figures).
- The collapsed range/filter row stays collapsed after it is applied: Show range closes the form again (reports iter2, all five kinds).
- In a row's right column only the total is figure-sized; breakdown amounts are meta lines (pay iter, reports iter1 and iter2).
